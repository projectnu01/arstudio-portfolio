# Arnie Santos Portfolio - AR Studios

A modern, professional portfolio website for Arnie Santos showcasing photography, videography, and web development skills.

## 🚀 Features

- **Modern Dark Theme** - Sleek, professional dark design with accent colors
- **Fully Responsive** - Works on all devices (desktop, tablet, mobile)
- **Bootstrap 5** - Built with Bootstrap 5 for solid foundation
- **Smooth Animations** - AOS library for scroll animations
- **Interactive Elements** - Portfolio filtering, counter animations, particle effects
- **SEO Optimized** - Proper meta tags and semantic HTML

## 🎨 Customization

### Colors
Edit the CSS variables in `css/style.css`:

```css
:root {
    --primary-color: #eee400;      /* Main accent color (yellow) */
    --secondary-color: #53c1de;    /* Secondary accent */
    --bg-dark: #0a0a0a;            /* Background dark */
    --bg-darker: #050505;          /* Background darker */
}
```
